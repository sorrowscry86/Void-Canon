Void Canon 0.4.0 — Personal world library

Create independent worlds, characters, and locations; import artwork before scene setup; choose a character/location pairing with its own saved draft, transcript, and chapter memory. Existing sample data and stable links are retained.

Requires Android 8.0 or newer. Download void-canon-0.4.0.apk and install over the existing app. The package and signing identity are unchanged. World → Worlds → New world starts a blank setting.

Validation: 40 JVM tests, Android lint, an Android 10/API 29 emulator walkthrough, and an in-place 0.3.1 → 0.4.0 upgrade passed. Physical-device verification and live provider behavior remain separate. This is an early debug build.

The attached source ZIP is the source snapshot for this build and includes the implementation handback, roadmap, build instructions, and test evidence. SHA-256 files are included for both downloads. No provider keys, signing keys, or user-created on-device worlds are bundled.
