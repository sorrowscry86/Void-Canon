The files in [specifications](specifications/START-HERE.md), including the original PDF, preserve the larger product vision and historical stage briefs. They are not a list of completed features. Current user decisions and the implementation handback settle the actual name, stack, provider, supported behavior, and immediate scope.

Automated provider checks use a local test server; model-picker screenshots use labeled fixtures. Emulator results do not establish physical-phone performance or current OpenRouter quotas/model availability. User-created worlds and provider/signing secrets are not included in the repository or release source snapshot.
